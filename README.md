# 著作権のきほん

コピー・引用・SNS への投稿・写真の写り込み・保護期間など、身近な場面で「してよい？いけない？」を確かめる1日5問の学習ゲームです。正解すると、もとになった著作権法の条文や文化庁の説明が出ます。

遊ぶ: <https://satou-aaaaa.github.io/chosakuken/>

## 遊び方

- 今日の5問（だれでも同じ・1日1回）：身近な場面の問題を3つの答えから選びます。
- 上級（むずかしい場面3問・ヒントなし）・練習（分類ごと・何度でも）・とことん（まちがえても続き、「ここで降りる」まで）・おさらい（まちがえた問題）
- 著作権帳（82の場面と出典）・実績・カレンダー（取りこぼした過去7日をあとから）
- 時間制限なし。記録は遊ぶ人のブラウザ（localStorage）だけに置き、外へ送りません。

## 中身の出どころ

著作権法の条文（e-Gov 法令検索、2026年11月の版）と、文化庁の「著作権テキスト」・Q&A・講習会の資料から作りました（一覧は `data.js` の `SRC` と、ゲームの「このゲームについて」）。問題を出す人物は作り話です。

- 決まりを知るための学習用で、法律相談ではありません。人によって考え方が分かれる場面（スクリーンショットの投稿・二次創作・AI など）は問題にしていません。
- 仕事で使うときや迷うときは、作品の利用規約や権利を持つ人に確かめてください。
